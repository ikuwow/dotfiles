# Documentation Lookup

- Search a vendor's own docs MCP server before Context7 or DeepWiki when the question is about that vendor's product (a vendor's server searches its current official documentation, while Context7's instructions claim cloud services too)
  - AWS: `aws-knowledge`
  - Google Cloud and other Google developer products, Go included: `google-developer-knowledge`
  - Datadog: the Datadog connector's documentation search
- For a product without such a server, use Context7 or DeepWiki
